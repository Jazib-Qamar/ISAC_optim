# ICC figures — reproducibility

All figures are generated by `python -m experiments.icc_generate_paper` from CSV files in `raw_data/`.
Optimisers are not re-run.

## fig1_natural_asymmetry_mismatch
- Experiment command: `python -m experiments.icc_natural_tdl_mc`
- Raw data: `results/icc_paper/raw_data/icc_natural_tdl_mc_raw.csv`
- Compared methods: conventional_s2, exact_efim
- x-axis: |f_bar_P| [kHz]
- y-axis: epsilon_J [%]
- Sample size: 500
- CI method: none (scatter)
- Channel model: exponential PDP TDL
- Physical sensing target: Γ_J = 0.5 J_max (unknown-amplitude), uniform-spectrum PSL request for PSL methods
- PSL definition: independent dense grid, mainlobe exclusion 1/B
- Scientific question: Natural asymmetry vs conventional S2 mismatch
